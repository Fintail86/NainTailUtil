# NainTailUtil

NainTailUtil은 포터블 Windows 유틸리티를 독립 실행 가능한 애드온으로 구성하고, 하나의
홈에서 발견하고 실행하는 애드온 호스트 프로젝트입니다.

## 구성

- **NainTail**: 애드온 검색, 홈 화면, 실행 전환과 공용 의존성 연결을 담당하는 호스트
- **NaiTail**: NovelAI 이미지 생성 애드온
- **AnimaTail**: 로컬 이미지 생성 애드온
- **GalleryTail**: 생성 결과 탐색 애드온
- **CensorTail**: 로컬 자동검열 애드온

각 애드온은 단독 실행 가능한 포터블 유틸리티를 목표로 하며, NainTail에 장착되면 호스트가
제공하는 공용 런타임과 서비스를 사용할 수 있습니다. GUI, CLI와 MCP 진입점을 같은 Core 및
Worker 계층 위에 연결하는 구조로 개발하고 있습니다.

## 현재 상태

현재 개발 중입니다. 소스 코드, 포터블 제품, 런타임·모델과 릴리스 바이너리는 아직 이
저장소에 공개하지 않았습니다. 배포 경계와 검증 절차가 확정된 뒤 순차적으로 게시할 예정입니다.
