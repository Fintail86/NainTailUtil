# CensorTail 자동검열

- 애드온 경계 적용일: 2026-08-15
- 참고 UX: PeroPix 2.3.4
- 구현 방식: CensorTail 전용 Electron IPC + 별도 Python ONNX worker

## 처리 흐름

1. 자동검열 탭에 진입한다. 모델 파일과 런타임이 준비되어 있으면 별도 worker가 ONNX
   세션만 미리 생성한다. 이 단계에서는 이미지 입력이나 부위 검출을 실행하지 않는다.
2. PNG, JPG, JPEG 또는 WebP 파일을 선택하거나 파일·폴더를 입력 패널에 드롭한다.
   폴더는 전체 하위 폴더를 재귀 검색하되 심볼릭 링크는 따라가지 않는다. 이미지가
   200장을 넘으면 200장 단위 임포트 큐로 나눠 전체 목록을 순차 등록한다.
3. 최초 사용 시 고정된 XL ONNX 모델을 원 배포처에서 직접 다운로드한다. 탭을 열어 둔
   상태에서 다운로드가 끝난 경우에도 곧바로 모델 세션만 미리 생성한다.
4. 검열 대상 class와 class별 confidence 임계값을 선택한다.
5. 사용자가 `자동 검출 시작`을 누르면 그때 이미지를 순차 추론하고 원본 픽셀 좌표의
   직사각형 후보를 반환한다. 미리 로드된 세션을 재사용하므로 첫 검출 대기 시간이 줄어든다.
6. 미리보기에서 후보를 켜고 끄거나 이동·크기 조절·삭제한다. `+ 수동 영역`을
   켜면 이미지 위를 직접 드래그해 필요한 만큼 박스를 추가할 수 있다.
7. 모자이크, 색상 박스, 형태 칠하기, 그라데이션 또는 포그를 적용해
   `outputs/censored/`에 저장한다. 폴더 입력은
   `outputs/censored/<드롭한 폴더명>/<원본 상대 경로>` 구조를 깊이 제한 없이
   유지한다. 분석과 저장도 200장 단위로 나누되 전체 등록 이미지를 처리한다.
8. 검출 박스, 효과 설정과 모델 식별자는 결과 이미지 내부 metadata에 저장하며
   별도 JSON sidecar는 만들지 않는다.

원본 이미지는 수정하지 않는다. 기본값은 같은 이름이 이미 있으면 `_2`, `_3`처럼
새 이름을 사용하며 사용자가 덮어쓰기를 켠 경우에만 기존 검열 결과를 교체한다.

## 입력 이미지 패널

- 입력 이미지는 좌측 독립 패널의 정사각형 썸네일 그리드로 표시한다.
- 패널은 최소 300px을 유지하며 미리보기와의 경계선을 드래그해 620px까지 확장할 수
  있다. 현재 화면에서 미리보기·설정 패널에 필요한 폭은 항상 남긴다.
- 경계선은 키보드 좌우 방향키로도 조절하며, 두 번 클릭하면 기본 340px로 돌아간다.
- 각 타일은 순번, 파일명·상대 경로와 검출 후 후보 개수를 표시한다.

## 수동 영역과 효과

- 수동 영역은 자동 검출 전에도 추가할 수 있으며, 이후 자동 검출을 실행해도 유지된다.
- 수동 영역을 켠 동안 미리보기에서 시작점부터 끝점까지 드래그하면 직사각형 편집
  영역이 생긴다. 10px보다 작은 오동작 드래그는 등록하지 않는다.
- 수동 영역 모드에서도 기존 박스나 8방향 크기 조절 핸들을 누르면 새 영역 생성보다
  선택·이동·크기 조절을 우선한다. 새 영역은 박스가 없는 이미지 부분에서만 시작한다.
- 선택된 박스는 화면의 삭제 버튼 또는 키보드 `Delete`로 제거한다. 입력 필드 편집
  중인 `Delete`는 박스 삭제로 처리하지 않는다.
- 그라데이션은 편집 영역의 중심을 기준으로 사용자 색상을 채우고 타원형으로
  투명해진다. 중심 범위와 중심 불투명도를 조절할 수 있다.
- 포그는 선택 영역의 정확한 중심에서 여러 개의 부드러운 증기 덩어리가 겹친 뒤
  바깥으로 퍼지는 구름 마스크다. 겹친 부분은 자연스럽게 진해지고 외곽 덩어리는
  작고 옅어지며 중앙 가림을 약화시키지 않는다.
- 형태 칠하기는 모델의 32채널 분할 prototype과 검출별 mask coefficient를 합성해
  부위 윤곽만 사용자 색상으로 채운다. 원본 좌표에 맞춘 고해상도 마스크를 사용하며
  `형태 칠하기` 버튼을 누를 때 수동으로 변형한 자동 검출 박스를 마스크 범위로 다시
  맞춘다. 마스크가 없는 수동 영역은 위치를 유지하고 안전하게 색상 직사각형으로 대체한다.
- 형태 칠하기와 그라데이션의 `확산 범위`는 0~100%의 추가 확산량이다. 0%는 기존 기본
  범위이며 값을 높일수록 형태 마스크는 바깥으로 팽창하고 그라데이션은 중심에서 퍼지는
  반경이 최대 60%까지 넓어진다.
- 포그는 확산 범위 대신 `포그 밀도` 0~100%를 사용한다. 영역 크기는 유지한 채 낮은 값은
  성긴 증기, 높은 값은 빈 공간이 적고 진한 증기로 합성한다. 기본값은 70%다.
- 사용자 색상을 사용하는 색상 박스·형태 칠하기·그라데이션·포그의 초기 색상은
  흰색이다. 포그는 선택 색상과 `포그 밝기`를 함께 사용한다.
- 고정 검정·흰색 박스 모드는 제거했다. 색상 박스에서 같은 색상을 선택할 수 있으며,
  이전 요청의 `black`과 `white` 값은 내부에서 해당 색상 박스로 호환 변환한다.
- 포그는 중심 증기 5개와 밀도에 따라 10~18개의 안쪽·바깥쪽 증기 덩어리를 알파
  중첩 방식으로 합성한다. 기본 밀도에서도 겹친 중심부가 불투명하게 가려지며 같은
  박스 좌표에서는 항상 같은 모양을 사용한다.
- 포그는 작은 검출 영역에서도 외곽 감쇠 공간을 확보하도록 영역 크기에 따라 자동으로
  약간 확장된다. 공통 `영역 확장`과 `경계 흐림`도 추가로 적용된다.
- 미리보기 상단의 `원본`은 박스와 효과가 전혀 없는 순수 원본만 표시한다. 박스 생성,
  선택, 이동, 크기 조절과 실제 효과 합성 결과 확인은 모두 `검열 미리보기`에서 한다.
  검열 미리보기는 디스크에 파일을 만들지 않고 Python worker가 현재 박스와 설정을
  원본 픽셀에 적용한 뒤 메모리 이미지로 반환한다.
- 미리보기 좌상단에서 화면 맞춤과 실제 크기 `1:1`을 선택한다. 마우스 휠은
  10~800% 범위로 확대·축소하며 이미지가 화면보다 큰 경우 빈 영역을 드래그해 이동한다.
  원본과 검열 미리보기는 같은 확대율과 위치를 유지해 바로 비교할 수 있다.
- 박스나 효과 설정이 변경되어도 사용자가 선택한 원본/검열 보기 상태는 바뀌지 않는다.
  입력 이미지 목록에서 다른 이미지를 선택해도 이 보기 상태를 그대로 유지한다.
  검열 미리보기에서는 변경 즉시 현재 효과의 편집용 표현을 보여주고 180ms debounce 후
  최신 설정의 실제 합성 이미지로 자동 교체한다. 합성 요청이 이미 실행 중이면 마지막
  변경 요청만 이어서 처리한다.
- 여러 박스가 겹치면 선택 박스를 가장 높은 z-order로 올린다. 크기 조절 손잡이는 선택
  박스에만 상·하·좌·우와 네 모서리의 8방향으로 표시한다. 화면에 표시된 박스의 너비나
  높이가 56px 미만이면 조작이 겹치지 않도록 네 모서리 손잡이만 남긴다.
- 수동 박스는 이미지 경계를 넘어갈 수 있다. 이동할 때는 최소 8px만 이미지 안에
  남기며 드래그 생성과 우하단 크기 조절은 이미지 밖 좌표를 보존한다. 최종 합성은
  원본 캔버스와 겹치는 픽셀만 계산하므로 바깥쪽 효과가 경계에서 잘리고 출력 이미지의
  크기나 원본 구도는 변하지 않는다.

실제 합성 응답을 기다리는 동안 검열 미리보기의 박스 안에 표시되는 색·형태는 편집
위치를 빠르게 확인하기 위한 근사 표현이다. 순수 원본 모드에는 박스와 효과를 표시하지
않는다. `검열 미리보기`의 합성 이미지와 최종 저장 픽셀 효과는 같은 Python 합성 함수를
사용한다.

## 모델 manifest

| 항목 | 값 |
|---|---|
| 저장소 | `01miku/anime-nsfw-segm-yolo26` |
| 파일 | `nsfw-anime-xl-x1280.onnx` |
| revision | `1697d5d1827b6a818b350b44bf3ec27f08837a2a` |
| bytes | `126350117` |
| SHA-256 | `92046f77852b3e3d3a3ddf74575dd9d11f79f832af8d2d3e7eac186ba379194a` |
| 입력 | 동적 크기 RGB tensor, 앱 입력은 letterbox 1280×1280 |
| 모델 출력 class | anus, nipple, penis, vagina, female face, male face, pubic hair |
| 검열 대상 class | anus, nipple, penis, vagina, pubic hair |

다운로드는 `.part` 파일로 받고 byte 수와 SHA-256이 모두 맞은 뒤에만 최종 파일명으로
원자적으로 이동한다. 앱과 저장소에는 모델 파일을 번들하지 않는다.

## 런타임

- `onnxruntime-gpu==1.26.0`
- CUDA 12.x / cuDNN 9 계열
- `CUDAExecutionProvider` 우선, 사용할 수 없으면 CPU provider로 fallback
- 시스템 Python, 시스템 CUDA Toolkit과 사용자 `PATH`를 사용하지 않는다. Standalone은
  `CensorTail/runtime/`, Hosted는 NainTail이 주입한 `<NainTailRoot>/runtime/`의 Python/CUDA와
  PyTorch CUDA/cuDNN DLL을 사용한다. Hosted에서 애드온 로컬 runtime으로 암묵 fallback하지 않는다.

ONNX Runtime 1.27.0의 현재 Windows wheel은 CUDA 13 계열이라 이 프로젝트의 PyTorch
2.11.0+cu128 런타임과 맞지 않았다. 실제 DLL 로딩을 확인한 1.26.0을 고정한다.

이전 RTX 5090 개발 PC 측정에서는 XL 모델의 첫 CUDA scan에 세션 준비 비용이 포함됐고,
같은 worker의 두 번째 scan은 약 0.02~0.09초였다. 현재는 세션 준비를 자동검열 탭 진입
시점으로 옮기고, 앱 실행 중 worker와 모델 session을 유지한다. 따라서 이미지 검출
버튼을 누른 뒤에는 이미 준비된 세션을 재사용한다. 이 값은 현재 PC의 관찰값이며 다른
환경의 성능 보장은 아니다.

## 라이선스 경계

- Hugging Face 저장소 model card: MIT
- 실제 ONNX metadata의 `license`: AGPL-3.0
- ONNX Runtime: MIT

저장소 표시와 파일 내부 metadata가 충돌하므로 CensorTail은 이 모델을 재배포하거나
설치물에 포함하지 않는다. UI에 충돌 사실을 표시하고 사용자가 선택한 경우에만 고정
원본 URL에서 직접 다운로드한다. 향후 안정화 배포 전에 모델 저작권자가 의도한 최종
라이선스를 별도로 재확인해야 한다.

## 현재 경계

- 모델의 female face와 male face 출력은 검열 대상으로 사용하지 않는다. 자동검열은
  성인 에셋의 주요 부위 검열 기능이며 얼굴 익명화 기능이 아니다.
- 자동 검출은 bounding box와 segmentation mask를 함께 사용한다. 마스크 주변에 여유
  범위를 둔 뒤 원본 이미지 좌표에 맞춰 최대 512px까지 확대한 grayscale PNG로 압축해
  편집 중에만 유지한다. 저장 결과의 이미지 내장 메타데이터에도 큰 base64 본문은
  기록하지 않는다.
- 수동 편집 영역 자체는 직사각형이며 회전 박스와 자유형 polygon 편집은 지원하지
  않는다. 그라데이션은 타원형 감쇠를 사용하고 포그는 비정형 증기 마스크를 사용하므로
  두 모드 모두 직사각형 외곽이 결과에 그대로 남지 않는다.
- PeroPix 코드는 복사하지 않았고 사용자 흐름만 참고해 별도로 구현했다.
