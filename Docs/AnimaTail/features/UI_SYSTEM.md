# UI 시스템과 피드백 규칙

- 기준일: 2026-07-27
- 적용 범위: `src/renderer/` 전체

## 타이포그래피

UI 기본 서체는 앱에 번들한 `Pretendard Variable`, 숫자·파일명·Seed·해상도·시간 같은
고정폭 정보는 `JetBrains Mono Variable`이다. 두 폰트는
[`main.jsx`](../../../Artifacts/anima-addon-renderer-build-v1/src/renderer/main.jsx)에서 패키지 CSS를 직접 불러오므로 시스템 설치
여부에 의존하지 않는다.

| CSS 토큰 | 값 | 용도 |
|---|---:|---|
| `--font-size-title` | 22px | 페이지 제목 |
| `--font-size-heading` | 15px | 섹션 제목 |
| `--font-size-body` | 13px | 입력값·버튼·본문 |
| `--font-size-caption` | 12px | 라벨·카드 본문 |
| `--font-size-min` | 11px | 보조 정보의 최소 크기 |
| `--font-weight-normal` | 400 | 본문 |
| `--font-weight-medium` | 500 | 라벨·버튼 |
| `--font-weight-bold` | 700 | 제목·강조 |
| `--text-primary` | `#ededf2` | 주 텍스트 |
| `--text-secondary` | `#a0a0b0` | 보조 텍스트 |
| `--text-tertiary` | `#606070` | 비활성·힌트 |

신규 UI는 위 크기·굵기·텍스트 색상 토큰을 사용한다. 11px 미만 텍스트와 컴포넌트별
임의 font-size·font-weight는 추가하지 않는다. 본문은 `letter-spacing: -0.01em`,
`line-height: 1.5`, 제목은 `line-height: 1.3`을 기본으로 한다. 숫자 열에는
`font-variant-numeric: tabular-nums`를 함께 사용한다.

## 공통 배치

- 상단 탭은 좌측 정렬이며 탭마다 별도 페이지 상태를 가진다.
- 싱글·멀티 생성은 좌측 설정, 중앙 미리보기, 우측 작업 목록의 3단 구조다.
- 생성 버튼은 좌측 패널 하단에 고정하고, 늘어나는 입력·설정은 그 위에서 스크롤한다.
- 중앙 작업 결과는 미리보기 하단에 붙이고 남은 높이를 큰 이미지 영역에 사용한다.
- 자동검열 입력 목록은 최소 너비가 있는 좌측 레이어로 두고, 세로 경계선으로 너비를
  조절한다. 다량 입력은 한 줄 목록 대신 정사각형 썸네일 그리드로 표시한다.
- 긴 프롬프트·파일명·오류는 카드 높이를 무한히 늘리지 않고 말줄임 또는 제한된 줄 수로
  표시하며 `title`로 전체 값을 확인할 수 있게 한다.

## 확인·오류·상태 피드백

- 파일·프리셋을 휴지통으로 보내거나 편집 내용을 버리는 동작은 브라우저 기본
  `confirm()` 대신 앱 내부 `ConfirmDialog`를 사용한다.
- 확인 대화상자는 취소 버튼에 먼저 포커스를 주고 `Escape`, 배경 클릭, 취소 버튼으로
  닫을 수 있다.
- 새 프리셋 이름은 별도의 `PresetNameDialog`에서 입력하며 저장 중에는 중복 제출과
  닫기를 막는다.
- 생성 오류는 우측 작업 목록 하단의 제한 높이 알림으로 표시한다. 개별 작업 오류도
  해당 카드에서 최대 줄 수를 제한한다.
- 자동검열의 다운로드·모델 로드·임포트·검출·저장 진행률과 오류는 우측 설정 패널
  하단의 실행 버튼 위에 표시한다.
- 키보드 사용자를 위해 전역 `:focus-visible` 포커스 링과 대화상자 role/aria 속성을
  유지한다.

## 접기·펼치기 상태

- 싱글·멀티의 샘플러·스케줄러 고급 설정은 기본 접힘이며 현재 조합을 요약 행에 표시한다.
- 멀티 서브 프롬프트 카드의 `프롬프트`, `네거티브`, `LoRA`는 각각 독립 토글이다.
  새 카드와 프리셋 적용으로 만든 카드는 프롬프트만 펼치고 나머지 둘은 접는다.
- 서브 카드의 접힘 상태는 카드 ID에 붙은 UI 로컬 상태다. 순서를 이동해도 같은 카드를
  따라가며, 접어도 입력값과 LoRA 선택은 삭제되지 않는다.
- 접힘 상태 자체는 작업 메타데이터나 프리셋 JSON에 저장하지 않는다.

## 색상과 효과 UI

일반 상태·성공·경고·오류와 입력 표면 색상도 `:root` 토큰을 사용한다. 자동검열 효과의
사용자 선택 색상은 생성 UI 테마 토큰과 별개인 작업 데이터이며, 기본값은 흰색이다.
