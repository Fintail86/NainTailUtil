# NainTail 호스트 0.1.6 업데이트 안내

## 수정 내용

설치 폴더 안에서 BAT로 실행한 상태에서도 업데이트할 수 있도록 프로그램 파일 교체 방식으로
전환했다. 설치 루트와 `Addons/`, `config/`, `outputs/`, `runtime/`은 이동하지 않는다.
코드만 백업하고 파일별 원자적 교체를 수행하며, 중단 시 재개하거나 이전 코드로 롤백한다.

## 0.1.5 이하에서 최초 업데이트하는 경우

구버전은 내려받은 새 버전이 아니라 **현재 설치된 적용 스크립트**를 먼저 실행한다.
따라서 0.1.6 ZIP을 게시하는 것만으로 기존 적용기의 폴더 잠금 문제가 사라지지는 않는다.
아래 한 파일 교체를 먼저 진행한다. 설치 폴더나 사용자 데이터 폴더를 삭제하지 않는다.

1. NainTail과 해당 설치본의 애드온 창을 모두 종료한다.
2. 공식 `NainTail-v0.1.6-win-x64.zip`을 별도 임시 폴더에 압축 해제한다.
3. 압축을 푼 `NainTail/bootstrap/apply-host-update.ps1` 파일 하나를 기존 설치본의
   `bootstrap/apply-host-update.ps1`에 복사하여 덮어쓴다.
4. 기존 설치본의 `NainTailUtil.bat`를 실행한다.
   - 미완료 업데이트가 있으면 새 적용기가 기존 transaction을 읽고 복구한다.
   - 미완료 업데이트가 없다면 호스트 설정에서 0.1.6 업데이트를 진행한다.
   - 미완료 transaction의 대상이 0.1.5이면 우선 그 버전의 복구를 완료한 뒤 0.1.6으로 갱신한다.

애드온·설정·출력·런타임은 그대로 사용한다. `%TEMP%`나 상위 폴더에서 실행하도록 바꾸는
절차가 아니며, 원래 설치 폴더 안에서 기존 BAT를 실행한다.

## 주의할 구분

- 0.1.6에는 수정된 적용기가 포함된다. 이후 업데이트는 이 파일 교체 절차가 필요 없다.
- 호스트만 0.1.6으로 갱신한다. NaiTail 0.1.1, CensorTail 0.1.2,
  AnimaTail 0.1.1, GalleryTail 0.1.0은 변경하지 않는다.
- GitHub 초안은 앱의 업데이트 목록에 표시되지 않는다. 공식 발행 후 업데이트할 수 있다.

## 이번 릴리즈 준비 검증

- 적용기 개발 테스트 16개: 관련 소스가 동일한 두 suite의 이전 통과 지문 재사용.
- 호스트 릴리즈 테스트: 이번 실행 6개 suite 통과. 대상 밖 54개 suite 스킵.
- 실제 0.1.5 패키지 복사본에 위 한 파일 교체 절차를 적용한 뒤, 설치 폴더를 작업 경로로
  유지하며 0.1.6 업데이트 성공. 새 코드 해시와 설치/사용자 디렉터리 식별자 보존 확인.
- 실제 Electron 호스트 GUI 기동 및 폴더 이동 후 재기동 성공. 샌드박스의 최초 GUI 파일 로딩
  차단은 일반 Windows 권한에서 재검증했다. 실제 사용자 설치본에는 적용하지 않았다.
- ZIP 추출 무결성 및 SHA-256·파일 크기·manifest 정합성, 배포 파일의 Git 추적 여부 검증 통과.
- 애드온별 전 범위 검증·GPU 검열·유료 이미지 생성은 이번 범위 밖으로 실행하지 않았다.
